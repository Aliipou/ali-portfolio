# Ali Pourrahim — Portfolio

### 🟢 [Live demo](https://ali-portfolio-psi-six.vercel.app)

Personal portfolio site — B.Eng. Information Technology graduate (Centria,
2026), Helsinki. Full-stack software, backend systems, cloud infrastructure.
Six featured case studies with real facts, stack, and links to live demos
and source, plus the rest of the project list. Content is sourced directly
from a maintained portfolio data file (`projects.yaml`/`profile.yaml`) — no
project claim here is invented.

## Stack

Next.js (App Router) + TypeScript, static-generated (`next build`), no
backend — this is a content site, not an app.

## Running locally

```bash
npm install
npm run dev
```

## Deploying

```bash
vercel deploy --prod
```
